# 🍴 Food Ordering App (Single Restaurant app)

A full-stack food ordering website developed for a single restaurant using the MERN stack.

Customers can view the menu, add food items to cart, place orders, and complete the checkout process.

---

 🚀 Features

### Customer Features

- 🏠 Restaurant Home Page
- 🍽️ Menu Display
- 🖼️ Food Images
- 🛒 Add to Cart
- ➕ Increase Quantity
- ➖ Decrease Quantity
- ❌ Remove Items
- 💰 Automatic Price Calculation
- 📝 Checkout Page
- 📦 Order Placement
- 💳 Payment Placeholder



 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- React Router
- Context API
- Axios
- CSS

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose
